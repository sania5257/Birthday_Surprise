# Doraemon Birthday Surprise 💙🎂

A cute, responsive birthday surprise website with a Doraemon-inspired blue theme, birthday message, photo memories, cake wish interaction, and optional music.

## Quick setup
1. Upload all project files to your GitHub repository.
2. Put your photos in the `images` folder and name them `photo1.jpg`, `photo2.jpg`, and `photo3.jpg` (or update the image paths in `index.html`).
3. Add an MP3 file at `audio/birthday.mp3` if you want music.
4. Open your repository → **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Your website will appear at `https://sania5257.github.io/Birthday_Surprise/` after GitHub Pages finishes deploying.

## Personalize
- Change `Birthday Star` in `index.html` to the recipient's name.
- Edit the birthday message and the reminder text in `index.html`.
- Replace the emoji robot placeholders with a Doraemon image if desired (use an image you have permission to use).
- Change colors in `style.css` under `:root`.

## Files
- `index.html` — page sections and text
- `style.css` — theme, layout, and animations
- `script.js` — interactive surprise and wish button
- `images/` — add your photos here
- `audio/` — optional birthday music
